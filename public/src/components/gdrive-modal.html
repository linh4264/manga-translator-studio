Đồng Bộ & Làm Việc Nhóm Qua Google Drive

Xuất/nhập tệp dự án làm việc chung giữa Translator, Proofreader và Typesetter

Lấy Token miễn phí qua OAuth Playground (30 giây):

  1. Bấm nút Lấy Access Token Nhanh bên trên (mở OAuth Playground)
  2. Ở cột trái Step 1, cuộn tìm Drive API v3 → Tích chọn ../auth/drive (quét toàn bộ thư mục Drive) hoặc ../auth/drive.file
  3. Bấm nút xanh Authorize APIs → Đăng nhập tài khoản Google
  4. Ở Step 2, bấm Exchange authorization code for tokens
  5. Copy chuỗi Access token (dạng ya29.a0...) → Dán vào ô bên dưới → Bấm Lưu Token
